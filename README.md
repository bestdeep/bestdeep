## 🧑‍💻 About Me

I build at the intersection of **machine learning** and **decentralized networks**. Most of my recent work
is on **Bittensor subnets**: writing miners, validators, and the agents, models, and data pipelines behind them.
I also build the full-stack pieces around them, including APIs, dashboards, browser extensions, and DeFi integrations.

- 🧠 **LLM training:** distillation of MoE giants, LoRA/SFT/DPO/GRPO, LLM-judge data pipelines, high-throughput inference
- 🤖 **LLM agents:** SWE-bench solvers, RL-trained agents, and multi-environment agent collections
- 👁️ **Computer vision & video:** classifiers, video compression and enhancement, biometrics
- ⛓️ **Blockchain:** Bittensor subnet miners/validators, network-monitoring and trading bots (Bittensor, Sui), presale dApps, DeFi adapters, Bitcoin NFT wallet tooling
- 🌐 **Full-stack:** Python backends, TypeScript/JavaScript frontends, dashboards
- 📫 Open to collaboration and new opportunities

### 🔒 Private Work Highlights
<sub>Source is private; summaries only.</sub>

**LLM training, distillation & inference**
| Area | Summary |
|---|---|
| **Large-scale model distillation** | Competitive model distillation on a Bittensor subnet: compressing a 1T-param MoE teacher (Kimi-K2.6) into ≤33B students scored on a 25+ axis composite (math, code, reasoning, long-context, honesty) |
| **MoE fine-tuning toolkit** | Fine-tuning toolkit for DeepSeek-V3-architecture MoE models (Moonlight-16B-A3B): LoRA/QLoRA, full SFT, DPO with DeepSpeed ZeRO-2, and forward-KL distillation from a local or logprob-cached teacher, served with SGLang |
| **LLM-judge data pipeline** | End-to-end data pipeline: vLLM generation of king vs challenger replies, LLM-judge scoring, and SFT/DPO/GRPO/RFT dataset building on a MySQL-backed store |
| **Offline reward replica & RL training** | Offline replica of a subnet's multi-judge eval reward, used to ask "would this model win?" before spending an on-chain upload; includes SFT, DPO, self-play and online/offline GRPO trainers |
| **72B inference optimization** | Optimized Qwen2.5-72B serving image for a Bittensor inference subnet on 4×H200, tuned for TTFT and throughput under a strict logprob-correctness gate, with a local copy of the validator for scoring |
| **Agent evaluation framework** | Evaluation and training framework for AgentGym-style agent benchmarks: logic-reasoning dataset generation, QLoRA/SFT/MoE-routing training, and SWE, live-web and game environments |
| **Time-series generator tooling** | Measurement and cost-aware A/B sweep suite for time-series generator development on a Bittensor subnet, built on the subnet's real eval pool |
